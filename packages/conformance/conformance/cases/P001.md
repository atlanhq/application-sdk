# P001 cases — UnboundedContractFields

**Protects:** Temporal's 2MB payload limit. `allow_unbounded_fields` turns off the import-time payload-safety check, so an unbounded field fails in the tenant with the largest source.

**Done-bar:** the opt-out is removed, and every field it guarded is bounded, not only accepted by the check.

**Verify every case:** import the changed module (a base class or mixin can carry an `Any` that raises `PayloadSafetyError`), run the tests, and for an `@entrypoint` contract run `gen-contract-ledger` then `ledger-guard` and read the result.

**Also check:** B005 and ledger-guard (see the rule's `rule_interactions`). Narrowing a type in source does not change a recorded ledger entry; removing a recorded field fires B005.

**Not fixes:** `object`, `JsonValue`, a bare `dict` or `list`, a recursive alias, a nested `BaseModel(extra='allow')`, or `MaxItems` around `Any`.

## Index

If the finding names a case, use that row. Otherwise check every row against the site; the first two rows cover the whole class, the rest cover one unsafe field each, so pick a row for every field the finding names. Use a row only when you can confirm it as the row says. If no row matches a field, or you cannot confirm it, no case applies: list each condition and why it failed.

| id | condition | how to confirm |
|---|---|---|

## generated

Fix the source, not the generated file: the `contract/*.pkl` widget, or the toolkit when it emits `dict[str, Any]` for a widget (`APITree` and similar). Regenerate. Never hand-edit a generated file, and never let a post-generate hook put the opt-out back. Then use the case that matches each field in the regenerated contract.

## remove-opt-out

Remove the `allow_unbounded_fields` keyword, or the `_allow_unbounded_fields` attribute. `Input` drops undeclared keys with or without the opt-out, so extra arguments from a caller never justify it. Import the module: if a field inherited from a base class or mixin raises `PayloadSafetyError`, fix it in that class.

```python
-class TaskStats(Output, allow_unbounded_fields=True):
+class TaskStats(Output):
     total: int = 0
     files: Annotated[list[FileReference], MaxItems(100)] = []
```

## drop-override

Delete the override. The field inherits the safe type, and the wire shape does not change.

```python
 class ExtractInput(ExtractionInput):
-    connection: dict[str, Any] = {}
```

## sdk-type

Use the SDK type in the same outer shape: `ConnectionRef`; `CredentialRef` or `credential_guid` (credentials cross tasks by reference, never inline); `AgentCredentialSpec` for `agent_json`; a `BaseMetadataConfig` subclass for wizard metadata; `FilterMap` for filter maps; a small `BaseModel` for a dict whose keys are known. Absorb legacy wire shapes with a `mode='before'` validator. Confirm that each shape the field carries today still validates.

## bound-collection

Wrap the field in `Annotated[..., MaxItems(n)]`, with `n` from the field's real count. Every nested `dict` or `list` needs its own bound. `MaxItems` never makes `Any` safe.

```python
-    counts: dict[str, int] = {}
+    counts: Annotated[dict[str, int], MaxItems(500)] = {}
```

## by-reference

Write the data to the object store and pass a `FileReference`. This is the fix that holds at 2MB. Change the producer and every reader in the same change.

## retire-field

Mark the field `deprecated=True` with `json_schema_extra={'x-lifecycle': 'sunset'}`, regenerate the ledger, then remove the field from source.

## keep-opt-out

Do not change the code. The app owner decides, with each refusal named. If the owner keeps the opt-out, the directive is `# conformance: ignore[P001] <reason>`, and the reason names each alternative tried. The site stays an open migration item, because `check_migration` still fails on `allow_unbounded_fields=True`.
